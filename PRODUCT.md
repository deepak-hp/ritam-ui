# Serein

## Platform
web

## Purpose and users
An MIT-licensed React UI library for Deepak's future apps, with a public beta package prepared but not yet published and shared design foundations intended to extend to mobile and desktop later. Developers and coding assistants need reliable components, readable contracts and realistic examples.

## Capabilities and constraints
The current package provides 42 components and two hooks, compiled CSS, Storybook and offline/live AI documentation. Native platform adapters are future work. The reference app exercises the installed package through a component catalogue, project search, date/status filters, editable forms, and local invoice, settings, and onboarding demonstrations. Its sample data and saved preferences are local to the browser; it has no backend or accounts. The AI materials include source-fresh reviewed client-side workflow examples and a human-reviewed comparison protocol; they remain an illustrative pilot, not evidence of general AI improvement.

## Brand commitments
The user selected the Serein name and requested a visual redesign inspired by its properties. Preserve the previously approved Plus Jakarta Sans, orange primary fills with dark text, white light canvas and near-black dark canvas, restrained green, and clear controls. Serein introduces softer geometry and layered opaque surfaces; the working preview is available for visual review. The astrology-informed foundation is symbolic and does not prescribe exact hex values. DESIGN.md records the implementation.

## Evidence on hand
Source tokens in trial/src/tokens.css, component stories, trial/docs/VERIFICATION.md and trial/.review screenshots. Reference-app projects are explicitly fictional samples.

## Product principles

Coding assistants also receive task-oriented composition recipes in `trial/ai/COMPOSITION.md`. The reference app's Composition lab compares two independently generated invoice layouts using shared data and interactions. It is an illustrative pilot, not evidence that guidance generally improves AI design quality; see `trial/docs/COMPOSITION-PILOT.md`.
Use existing public APIs. Make every visible control work. Expose actionable recovery states. Document limits honestly. Keep integration simple and compiler-free for consumers.

Apple HIG informs hierarchy, navigation materials and accessibility within Serein. Support subtle and expressive navigation finishes plus solid fallback, while retaining the approved colour roles, font and crisp controls. Apply translucency to a single navigation plane; keep content surfaces opaque. See trial/docs/APPLE-DESIGN.md.

## Accessibility and inclusion
WCAG 2.2 AA is the target. Automated tests are evidence, not conformance certification; manual assistive-technology and applicable EAA review remain open.
