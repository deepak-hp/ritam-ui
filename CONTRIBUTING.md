# Contributing to Serein

Serein is an unpublished release candidate. Contributions are reviewed by the repository owner and do not authorize publication or change the license status.

## Before opening a change

- Keep changes focused and use the established React, TypeScript, token, and Storybook patterns.
- Add or update evidence for behavior changes. Run the smallest relevant check locally; use `npm run check:release` in `trial` for a release candidate.
- Do not commit private research, credentials, generated archives, browser profiles, or screenshots without a specific review need.
- Describe the user-visible change, validation performed, and any accessibility or compatibility limit in the pull request.

## Review and maintenance

The owner decides scope, versions, releases, and whether outside contributions are accepted. There is no response-time commitment. See [MAINTENANCE.md](MAINTENANCE.md) for supported scope and [SECURITY.md](SECURITY.md) for vulnerability reports.
