# Promotion drafts and demo outline

These are drafts for owner review after the release gate, license approval, and explicit publication authorization. They do not claim existing public availability, users, benchmarks, or accessibility certification.

## Short announcement draft

Ritam UI is a React web component library with typed components, compiled CSS, Storybook documentation, and practical AI composition recipes. Its Flame & Ink foundations support light and dark interfaces, while the reference workspace shows local invoice, settings, and onboarding flows. We are inviting early technical feedback on installation, component contracts, and accessible interaction details. The repository and documentation will be the source of truth when the package is made public.

## Demonstration outline

1. Show the package's Start Here catalogue and one typed component API.
2. Install the local package in the reference workspace and show the compiled CSS import.
3. Walk through invoice filtering and its simulated reminder failure/retry state.
4. Show settings validation, local persistence, and recovery from a failed save.
5. Show the onboarding flow, keyboard behavior, and its local-only boundary.
6. Show the AI contract and composition recipes, explaining that they are guidance and an illustrative pilot rather than a benchmark claim.

## Early feedback request

Ask reviewers to report the React/runtime version, installation path, component or flow tested, expected and observed behavior, and any accessibility or documentation gap. Record feedback as issues only after repository settings and moderation paths are ready.
