# Maintenance policy

Ritam UI currently supports the private React web package in `trial` on Node 24 and React 19. Native adapters, a hosted service, accounts, payments, email delivery, and accessibility conformance certification are outside the present support scope.

The owner reviews issues and pull requests when capacity permits. Releases are manually approved, versioned, and gated by the documented checks; no workflow publishes packages automatically. Breaking changes require a documented migration note and a major version after the package is publicly released.
